# 🧁 Pastelería Creativa – WPF (FlowDocument + DataGrid)

![Banner Pastelería Creativa](https://github.com/mariarosete/pasteleria/blob/main/screenshots/pasteleria.png?raw=true)

Aplicación de escritorio desarrollada en **WPF (C#)** que combina el uso de **FlowDocument** para contenido interactivo y un módulo de **acceso a datos con DataGrid** conectado a **Microsoft Access**.  
Permite gestionar recetas de repostería y visualizar contenido estructurado con una interfaz rica en estilos y animaciones.

## Funcionalidades destacadas

### 📄 FlowDocument
- Contenido estructurado en secciones (recetas, postres, decoraciones)  
- Guardar, cargar, eliminar e imprimir documentos  
- Uso de columnas, tablas, imágenes e hipervínculos  
- Interacciones mediante triggers (hover, click)  

### 📊 DataGrid (CRUD)
- Gestión de recetas almacenadas en **Microsoft Access**  
- Navegación por registros  
- CRUD completo (crear, editar, eliminar)  
- Visualización detallada de cada receta  

---

## 💻 Cómo ejecutar el proyecto

⚠️ Este proyecto no está desplegado. Se ejecuta en local.

1. Abre la solución en **Visual Studio**  
2. Asegúrate de tener **.NET y WPF** instalados  
3. Configura la ruta de la base de datos `recetas.accdb`  
4. Ejecuta el proyecto  

---

## Aspectos técnicos

- Uso avanzado de **FlowDocument** (columnas, tablas, estilos)  
- Implementación de **triggers y animaciones** en WPF  
- Integración de **DataGrid** con base de datos Access  
- Aplicación de arquitectura de escritorio con separación de vistas y datos  

---

## Objetivo del proyecto

- Practicar interfaces avanzadas en **WPF**  
- Implementar interacciones con triggers y eventos  
- Desarrollar acceso a datos con **DataGrid y Access**  
- Aplicar operaciones CRUD en aplicaciones de escritorio
